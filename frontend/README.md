# Maruthi Catalyst frontend

This bundle contains the React + Vite frontend source for the Maruthi Catalyst venture portal.

## Main files

- `index.html` — browser entry point and page metadata
- `src/App.tsx` — page structure and interactive idea form
- `src/index.css` — full visual system and responsive styles
- `src/main.tsx` — React entry point
- `attached_assets/maruthi-enterprises-logo-transparent.png` — cleaned brand logo

## Important note

The form currently validates entries and shows a confirmation state in the browser. Automatic email delivery still requires connecting an email service such as Resend and adding a server endpoint.
